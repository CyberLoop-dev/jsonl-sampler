## 🧭 Overview
Stream and sample JSONL records without loading the entire dataset.

## ✨ Features
- ✨ jsonl workflow
- ✨ sampling workflow
- ✨ data tools workflow
- ✨ python workflow

## 🎬 Demo
Run locally with your own input. No hosted demo is currently provided.

## 🚀 Quick Start
~~~bash
git clone https://github.com/CyberLoop-dev/jsonl-sampler.git
cd jsonl-sampler
python main.py --help
~~~
Python 3.10+; standard library only.
